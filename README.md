# Timer

[English](README.en.md) · **Русский**

![Timer](docs/banner.png)

Небольшой таймер обратного отсчёта в строке меню macOS.

- Клик по иконке открывает попап: введите время (клавиатура, скролл или стрелки) и нажмите «Старт».
- Зажмите иконку и потяните вверх/вниз, чтобы добавить или убрать минуты, пока таймер идёт.
- С зажатым Shift протяжка идёт шагом 5 минут с привязкой к :00, :05, :10… (включается в настройках).
- Правый клик по иконке открывает меню. Звук сигнала, громкость и длительность — в настройках.
- Горячие клавиши в попапе: `H` — пауза/продолжить, `C` — сброс (работают и в русской раскладке).

Интерфейс только на русском; локализации пока нет.

## Требования

macOS 14+, Swift 5.10 (Xcode или Command Line Tools).

## Сборка

```sh
./build.sh            # собирает dist/Timer.app (universal arm64 + x86_64)
./build.sh --install  # то же, затем копирует в /Applications
open dist/Timer.app
```

Приложение подписано ad-hoc и не нотаризовано. Если macOS не открывает скачанную копию,
нажмите на неё правой кнопкой и выберите «Открыть» или выполните `xattr -dr com.apple.quarantine Timer.app`.

Запускать нужно из `.app`-бандла (для уведомлений и автозапуска нужен bundle id); `swift run` не поддерживается.
